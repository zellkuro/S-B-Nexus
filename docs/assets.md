# Asset Packs Used

Which Unity Asset Store (or other) packs the world uses, so anyone can
rebuild the Unity project. **The pack files themselves are never committed**:
this repo is public, and Asset Store licences allow using assets in a game but
not sharing the files. Download them yourself from the links below.

How to choose and import packs: [Unity guide, Part 1B](unity-first-scene.md#part-1b-choose-and-import-your-models).
